## 이 저장소

포트폴리오 웹페이지 소스입니다. 빌드 도구 없이 동작하는 단일 정적 페이지로 만들었습니다.

```
index.html                      포트폴리오 페이지 (HTML + CSS + Vanilla JS, 외부 프레임워크 없음)
assets/froky-admin.png          FROKY VAPE 관리자 대시보드 스크린샷
.github/workflows/deploy-pages.yml   main 푸시 시 GitHub Pages 자동 배포
```

- 다크/라이트 테마 토글, 스크롤 스파이 내비게이션, 이미지 라이트박스(핀치 줌·드래그 팬)를 직접 구현했습니다.
- 폰트는 [Pretendard](https://github.com/orioncactus/pretendard)와 [JetBrains Mono](https://www.jetbrains.com/lp/mono/)를 CDN으로 불러옵니다. 둘 다 SIL Open Font License입니다.

## 로컬에서 보기

별도 빌드나 의존성 설치가 필요 없습니다.

```bash
git clone https://github.com/alswhitetiger/mingyun-portfolio.git
cd mingyun-portfolio
python3 -m http.server 8000   # http://localhost:8000
```

`index.html`을 브라우저로 직접 열어도 동작합니다.
